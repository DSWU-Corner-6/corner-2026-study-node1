깃이란? 코드 변경점을 기록하는 것이다. 버전 관리 도구라고도 한다. 

깃허브의 개념: 백업과 공유가 가능한 온라인 코드 저장소이다. 
깃허브로 백업가능하고, 링크를 통해 공유 가능, 협업 가능

깃: 코드 변경점 기록
깃허브: 온라인 백업, 공유, 협업 (온라인 코드 저장소)

Pwd print working directory
현재 내가 작업하는 폴더를 보여달라는 뜻
Ls list
내 폴더 안에 있는 폴더, 파일 내역을 보여줌
Ls -a list all
숨겨진 파일(보통 .으로 시작함)도 모두 볼 수 있음
Cd 폴더명 change directory
is명령어에서 확인된 폴더로 이동 가능
